# Controle de Estoque — ReplyMesh

## Descrição
Controle de entradas e saídas de estoque com alertas de nível mínimo.

## Funcionalidades
- Cadastro de itens com unidade de medida
- Registro de entradas (compras)
- Registro de saídas (consumo)
- Estoque mínimo com alertas
- Relatório de movimentações
- Exportação CSV

## Fluxo
1. Estoque > Itens de Estoque > Novo Item
2. Informe nome, unidade, quantidade atual e mínimo
3. Estoque > Movimentações para registrar entradas/saídas
4. Acompanhe alertas de estoque baixo

## Dúvidas Frequentes
**O estoque baixa automaticamente na venda?** Depende da configuração do produto.
**Posso exportar?** Sim, botão Exportar CSV na tela de Estoque.
**Quem pode acessar?** Apenas Admin.
