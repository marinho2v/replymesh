# Caixa (Cash Register) — ReplyMesh

## Descrição
Gestão completa do caixa: abertura, movimentações (suprimento/sangria) e fechamento.

## Funcionalidades
- Abertura com saldo inicial
- Registro de suprimento (adicionar dinheiro)
- Registro de sangria (retirar dinheiro)
- Histórico de movimentações
- Fechamento com conferência
- Relatório de caixa por período

## Como Abrir o Caixa
1. Financeiro > Caixa
2. Clique "Abrir Caixa"
3. Informe saldo inicial (dinheiro em espécie)
4. Confirme

## Como Fechar o Caixa
1. Financeiro > Caixa
2. Clique "Fechar Caixa"
3. Informe o saldo físico contado
4. Sistema calcula diferença
5. Confirme

## Dúvidas Frequentes
**Preciso abrir o caixa para usar o PDV?** Sim, obrigatório.
**O que é sangria?** Retirada de dinheiro do caixa durante o expediente.
**Quem pode acessar?** Admin e Caixa (cashier).
