# Configurações — ReplyMesh

## Descrição
Configurações gerais da loja: dados, horários, pagamentos e aparência.

## Funcionalidades
- Dados da loja (nome, endereço, telefone, CNPJ)
- Horários de funcionamento
- Métodos de pagamento aceitos
- Configuração de frete por zona
- Tema e cores do cardápio
- Domínio personalizado

## Como Configurar
1. Administração > Configurações
2. Preencha os dados da loja
3. Configure horários de funcionamento
4. Habilite formas de pagamento
5. Salve

## Dúvidas Frequentes
**Como mudar a cor do cardápio?** Configurações > Aparência > escolha o template.
**Posso usar domínio próprio?** Sim. Configure em Configurações > Domínio.
**Só admin acessa?** Sim, apenas perfil Admin.
