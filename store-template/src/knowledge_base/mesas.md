# Gestão de Mesas — ReplyMesh

## Descrição
Sistema completo para gestão de mesas, comandas e atendimento presencial com QR Code.

## Funcionalidades
- Cadastro de mesas com QR Code único
- Abertura e fechamento de comandas
- Pedidos pelo QR Code (cliente autoatendimento)
- Visualização de itens da comanda
- Aplicação de desconto
- Fechamento com múltiplas formas de pagamento

## Fluxo
1. Cadastrar mesa → QR Code gerado automaticamente
2. Imprimir/exibir QR Code na mesa física
3. Cliente escaneia → acessa cardápio digital
4. Cliente faz pedido → aparece no painel do garçom
5. Garçom confirma → vai para KDS da cozinha
6. Caixa fecha comanda → recebe pagamento

## Configuração
1. Menu lateral > Mesas
2. Clique "Nova Mesa"
3. Defina número/nome
4. QR Code disponível para impressão

## Dúvidas Frequentes
**Posso ter várias mesas abertas?** Sim, cada mesa tem sessão independente.
**Cliente precisa de conta?** Não. QR Code é acesso direto sem cadastro.
**Garçom pode abrir mesa manualmente?** Sim, pelo painel.
