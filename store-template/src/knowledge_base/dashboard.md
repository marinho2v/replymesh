# Dashboard — ReplyMesh

## Descrição
O Dashboard é a tela inicial do painel administrativo. Apresenta um resumo em tempo real das vendas, pedidos e indicadores do dia.

## Funcionalidades
- Total de pedidos do dia (por status)
- Faturamento do dia
- Gráfico de vendas por período
- Produtos mais vendidos
- Clientes recentes
- Alertas de pedidos pendentes

## Fluxo de uso
1. Faça login no painel
2. O Dashboard é carregado automaticamente
3. Use os filtros de data para comparar períodos
4. Clique em um pedido para ver detalhes

## Exemplos
- Ver quantos pedidos chegaram hoje: card "Pedidos Hoje"
- Identificar o pico de vendas: gráfico de linha por hora
- Ver qual produto mais vendeu: seção "Top Produtos"

## Dúvidas Frequentes
**Os dados são em tempo real?** Sim. Atualiza automaticamente conforme pedidos chegam.
**Como ver outro período?** Use o seletor de data no topo da página.
**Quem pode acessar?** Admin e Caixa (cashier).
