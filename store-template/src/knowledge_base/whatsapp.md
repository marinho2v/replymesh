# WhatsApp — ReplyMesh

## Descrição
Integração com WhatsApp Business para envio automático de notificações de pedidos.

## Funcionalidades
- Conexão via QR Code
- Notificações automáticas por status do pedido
- Templates personalizáveis
- Histórico de mensagens enviadas
- Logs de entrega

## Como Conectar
1. Comunicação > WhatsApp
2. Clique "Conectar WhatsApp"
3. Abra WhatsApp no celular > Dispositivos Conectados
4. Aponte a câmera para o QR Code
5. Aguarde confirmação

## Notificações Automáticas
- Pedido recebido
- Pedido confirmado
- Pedido em preparo
- Saiu para entrega
- Pedido entregue

## Problemas Comuns
**QR Code expirou:** recarregue a página para gerar novo (validade: 60s).
**WhatsApp desconectou:** reconecte pelo painel com novo QR.
**Número bloqueado pelo WhatsApp:** uso abusivo de disparos em massa.

## Dúvidas Frequentes
**Posso usar o mesmo número para outros fins?** Não recomendado. Use número dedicado.
**É compatível com WhatsApp Business?** Sim.
**Envio tem custo extra?** Não, incluso no plano.
